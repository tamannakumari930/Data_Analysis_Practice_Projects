# Data_Analysis_Practice_Projects

1. Sales Analysis Dashboard:-

# Objective:-
Analyze sales and GST data using an Excel dashboard

# Tools used:-
- Microsoft Excel
- Pivot Tables
- Pivot Charts 
- Slicers

# Dashboard Features:-
- KPI cards
- Sales Analysis
- State-wise analysis
- Month-wise analysis
- Firm-wise analysis

# Key Inishts:-
- SR enterprise generates the highest sales.
- The majority of sales are local.
- Sales show a peak in June.
- Haryana contributes higher sales.
